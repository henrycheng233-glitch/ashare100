# 前端（A股百强 · 公司档案）

纯静态单页网页：无构建、无外部依赖、无后端。图表全部为手写 SVG。

## 打开

直接双击 `index.html`（数据已内联在 `data.js`，`file://` 可用）。
或本地起服务：`python3 -m http.server 8787` 后访问 http://127.0.0.1:8787/

## 页面与路由

| 地址 | 页面 | 主要内容 |
|---|---|---|
| `#/` | 首页 · 市场总览 | 分四段：样本概况（指标条，营收 / 净利悬停看前 5 大贡献，板块条可点）→ 行业构成（树图 + 行业列表，双向联动）→ 百强榜单前 20（市值 / 领涨 / 领跌 / 成交额）→ 继续探索（数据观察排行卡，默认 3 张常用卡；热力图与涨跌分布折叠在「展开更多」里） |
| `#/list` | 榜单 | 100 家表格，分页（每页 20 / 50 / 全部，页码写进地址 `p` / `n`）；表头排序、行业 / 板块 / 指数 / 关键词筛选、营收迷你趋势图、方向键 + 回车 |
| `#/rank` | 排行中心 | 默认展开盈利能力、估值、股东回报、市场表现；规模、成长性、财务健康、股东与治理折叠在「展开更多指标」；最后是多条件现象（股息率高 · 市净率低、盈利质量、量价背离、分红稳定、ROE 主驱动） |
| `#/rank/<指标>` | 单指标全量排行 | 分布条带图、行业中位数（点击筛选）、统计、全部排名表（行业内排名 / 百强分位 / 较中位数 / 5 年趋势）、导出 CSV |
| `#/600519.SH` | 公司详情（默认「概览」） | F10 式布局：吸顶摘要条、左侧标签目录 + 同行业公司列表 |
| `#/600519.SH/<标签>` | 公司详情的某个标签 | `fin` 财务（含杜邦分解）· `holders` 股东 · `div` 分红 · `seg` 主营 · `peers` 同行 · `qa` 问答 · `ann` 公告 |
| `#/compare?c=代码,代码` | 公司对比 | 选 2–4 家；要点结论、雷达图（百强内 / 行业内百分位）、走势联动（可指数化）+ 每股派息、杜邦与股东结构、分组指标对照表 |
| `#/timeline?c=代码` | 时间轴 | 嵌入独立页 `timeline.html`：纵向时间脊柱，左侧四级制度演进（法律 / 顶层政策 / 市场制度 / 监管规则），右侧 100 家公司按精确上市或成立日期排布；顶部全景条的黄框可拖动、可伸缩；`c` 为高亮公司 |
| `#/industry?ind=银行&kpi=pe` | 行业 | 可点击的 KPI 卡切换指标视图、二级行业筛选、自定义轴散点图、行业公司表 |

`#/rank/<指标>` 的查询参数：`dir=asc|desc` 排序方向，`fin=1|0` 是否含金融业，`board=主板|科创板|创业板`，`ind=行业`。指标键见 `app.js` 中的 `METRICS`（如 `roe`、`pe`、`dy`、`cagr`）。

榜单筛选排序、排行筛选、对比所选公司、行业 KPI、公司标签都写进地址，可直接复制分享。

## 主要功能说明

- **数字格式**：全站数字经同一个格式层输出，整数部分一律千分位（如 `4,659亿`、`+1,468.08%`、`807,660 户`）。
- **浮层提示**：带 `title` / `data-tip` 的元素悬停即显示自定义提示；树图格子悬停列出成分公司。
- **行业树图**：按市值模式用单一中性色（面积即占比）；占比 < 1.2% 的行业合并为「其他」；标签按格子宽度显示全称 / 简称 / 不显示，不截断。
- **指标注册表 `METRICS`**：35 个指标，分 8 组（规模、盈利能力、成长性、估值、股东回报、财务健康、市场表现、股东与治理），含格式、优劣方向、口径说明。`fin: false` 的指标（毛利率、负债率等）在排行中默认剔除银行与非银金融，在同行 / 对比中显示「不适用」。
- **排行卡**：默认露出前 5，悬停后卡内可滚到前 20；竖线为百强中位数；底部进入全量页。
- **同行对比**：8 个一级分组 × 二级指标的矩阵表，格内显示数值、组内条与组内排名，底部为同行中位数与百强中位数，列头可排序。
- **散点图**：X / Y 轴可选任意指标，含 5 个预设视角；体量类指标自动用对数轴；标签避让、四象限角标、拖拽框选放大。
- **杜邦分解**：ROE ≈ 净利率 × 总资产周转率 × 权益乘数（期末值近似），标出各因子在百强中的分位与主驱动。
- **公司简介**：按句分段，抽取成立日期 / 上市地标签，附来源链接（东方财富 F10 公司概况）。
- **问答**：回复率与平均回复用时；按回复状态、来源筛选，全文搜索高亮。上证e互动无单条链接，显示为「上证e互动公司页」并可复制问题；第三方来源无回答时显示「来源未提供回答」。
- **公告**：按标题关键词分类（数据带 `category` 时优先使用），分类筛选 + 标题搜索。目前每家只收录最近约 20 条，页面注明全量条数并链接巨潮资讯。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 入口 |
| `style.css` | 设计变量（`:root`）与全部样式；断点 640 / 1024；末尾按 P0 / P1 / P2 分节 |
| `app.js` | 格式化、浮层提示、指标注册表、路由、各页面渲染与 SVG 图表（柱线组合、环形、矩形树图、雷达、散点、条带分布、热力图、迷你趋势） |
| `data.js` | `window.__DATA__`，由 `scripts/build_web.py` 从 `../data.json` 生成 |


## 设计与展示约定

- 视觉规范见 `../ui升级说明.md`：暖白 `#F7F6F0` + 墨绿 `#193B32`；涨跌按 A 股习惯红涨绿跌，且只用于涨跌语义。升级方案见 `../前端升级方案_v2.md`。
- 字段口径与空值文案以 `../字段说明_前端.md` 为准：缺失显示「—」并悬停说明原因；`0` 照常显示。
- 排行、组合筛选、◆ 最优、百分位、要点结论均为对现有数据的直接排序或计算，不构成投资判断，页面已注明。
- 7 家沪市公司的问答来自第三方（理杏仁、准上市），提问年份为推定，问答区下方已注明。
- 收藏与最近对比只存在本机浏览器（`localStorage`），换浏览器或无痕模式不保留。
- 系统开启「减少动态效果」时，动画自动关闭。
- 排行卡底部有「展开前 20」按钮，触屏无需悬停也能看到全部 20 名。

## 公司 Logo

- 图片在 `logos/`，文件名为「代码.扩展名」；来源与缺失情况记录在 `logos/logos.json`。
- 页面通过 `logos.js`（代码 → 文件名）读取，双击 `index.html` 也能显示。补全或替换 logo 后，在 `web/` 目录下重新生成：

```powershell
$j = Get-Content logos\logos.json -Raw -Encoding utf8 | ConvertFrom-Json; $o = [ordered]@{}; foreach ($p in $j.PSObject.Properties) { if ($p.Value.file) { $o[$p.Name] = $p.Value.file } }; Set-Content logos.js ("window.__LOGOS__ = " + ($o | ConvertTo-Json -Compress) + ";") -Encoding utf8
```

- 使用位置：公司页头部（64px）、顶栏搜索下拉与吸顶摘要条（22px）、榜单与首页榜单预览（24px）、对比页已选公司（28px）。缺失或加载失败时显示公司名首字。
